TRON Σ

المتصفح الذكي من الجيل القادم

تجربة تصفح فائقة السرعة مع مساعد ذكاء اصطناعي مدمج، خصوصية متقدمة، ودعم أصلي كامل للغة العربية

🚀 ابدأ الآن ✨ استكشف الميزات

ميزات قوية لتجربة استثنائية

اكتشف ما يجعل TRON Σ الخيار الأفضل للتصفح الذكي

🧠

مساعد ذكي مدمج

تلخيص الصفحات، ترجمة المحتوى، والإجابة على أسئلتك — كل ذلك مدمج مباشرة في المتصفح بدون إضافات خارجية.

🛡️

خصوصية متقدمة

حظر المتتبعات تلقائيًا، وضع التصفح الخاص المحسّن، DNS مشفر، وحماية بصمة المتصفح من التتبع.

⚡

أداء فائق السرعة

محرك عرض سريع مع تحميل كسول ذكي، إدارة ذاكرة متقدمة، وتجميد التبويبات غير النشطة تلقائيًا.

🌐

دعم عربي أصلي

واجهة كاملة باللغة العربية مع دعم RTL أصلي، محرك بحث مخصص، وخطوط عربية محسّنة.

🎨

تخصيص مرن

سمات متعددة، تخطيطات قابلة للتخصيص، إضافات قوية، وشريط أدوات قابل للتعديل بالكامل.

🔄

مزامنة سلسة

مزامنة عبر جميع أجهزتك مع تشفير من طرف إلى طرف — تبويبات، إشارات مرجعية، وإعدادات.

ابدأ في دقائق

ثلاث خطوات بسيطة لإعداد TRON Σ

1

استنساخ وتثبيت

# استنساخ المستودع

git clone https://github.com/tron-sigma/smart-browser.git

cd smart-browser

# تثبيت التبعيات

bun install

2

إعداد البيئة

# متغيرات البيئة

cp .env.example .env.local

# قاعدة البيانات

bun run db:push

3

تشغيل الخادم

# تشغيل التطوير

bun run dev

# أو استخدم TRON CLI

tron status

واجهة برمجة التطبيقات

API قوي ومرن لبناء التطبيقات والإضافات

GET /api/tabs

استرجاع جميع التبويبات المفتوحة مع معلومات الحالة والموقع

POST /api/tabs

إنشاء تبويب جديد مع تحديد عنوان URL والإعدادات

GET /api/ai/summarize

تلخيص محتوى صفحة ويب باستخدام الذكاء الاصطناعي

POST /api/ai/translate

ترجمة محتوى نصي بين اللغات المدعومة

PUT /api/settings

تحديث إعدادات المتصفح والتفضيلات الشخصية

DELETE /api/history/:id

حذف عنصر محدد من سجل التصفح
